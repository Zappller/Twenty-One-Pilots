# Atividade-de-Nivelamento-1-HTML-CSS-LAWD-

Explicando o site:

    O site é um tipo de homenagem a banda De Rock alternativo Twenty One Pilots.
    A primeira página tem dois wallpapers, tanto para celular quanto para computador, ambos são wallpapers diferente mas as funcionalidades são as mesmas. 
    Ao cliclar em "Tyler Joseph", o usuário é direcionado para a pagina do instagram do mesmo que é o vocalista da banda.
    Ao clicar em "Josh Dun", o usuário é direcionado para a pagina do instagram do mesmo que é o baterista da banda.
    Ao clicar em "Twenty One Pilots", o usuário é direcionado para o site da banda.
    Ao clicar no botão "Discografia", o usuário é direcionado para a pagina onde tem toda a discografia da banda que é a segunda página.
    Na segunda página, o usuário verá todos os albuns clicáveis lançados pela banda em ordem do mais antigo ao mais novo. Os albuns tem uma animação que ao passar o mouse por cima um disco de vinil sai do album, e ao clicar o usuário é redirecionado para o spotify onde está o album para o mesmo reproduzir caso queira
    Ambas as páginas tem uma frase no canto inferior direito escrito "Stay Alive", uma frase comum no fandom pois além de se tratar de um trecho da letra de música "truce" do album "vessel"(Música composta pelo Tyler, para o Josh), também tem um significado muito forte pois a banda aborda assuntos delicados como depressão, ansiedade e suicídio. Dito isso o a frase é clicável e leva até o site do CVV (Centro de Valorização a vida)

    Animações feitas no css e a fonte eu utilizei ajuda de IA (Deepseek)

    Para fazer uma fonte com direitos autorais estarem no projeto usei o prompt
    
"Seguinte, eu tenho uma fonte, que eu criei, gostaria de por num projeto html, como faço para fazer com que essa fonte fique para qualquer sistema que entre no meu site mesmo que não tenha essa fonte"


    Prompt para fazer o botão ter efeito Hover transparente (Ideia de Pedro designer)
    
"Fiz um botão em um projeto html/css, mas gostaria que fosse parecido com um vidro, com efeito ao passar o mouse por cima"



    Prompt para fazer o efeito do disco saindo do album
    
"Eu estou fazendo um projeto html, sobre uma banda, tenho o png do disco e de um vinil dele, gostaria de programar o disco, e quando a pessoa passa o mouse em cima o disco sai, como eu faço isso?"

    Prompt para suavizar a transição entre a pagina 1 e a pagina 2
    
"Preciso de suavizar de alguma forma sem uso de script js a transição após um click em um botão até a pagina que ele redireciona"
